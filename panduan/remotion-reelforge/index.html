Panduan · Video AI

Dari ide sampai Reels siap tayang.

Tutorial lengkap membuat video Reels dengan ReelForge: naskah dari ChatGPT, voice-over dari Cartesia, project Remotion dari Claude, lalu render MP4 di Google Colab.

Mulai dari langkah 1 Buka notebook ReelForge

Sekilas

  1. Level pemula, sekitar 45 menit, 30 langkah bergambar.
  2. Hasil: video vertikal 1080×1920 (9:16) sekitar 30 detik, siap diunggah ke Reels.
  3. Semua layanan cukup memakai akun gratis.
  4. Render berjalan di Google Colab, tanpa instalasi di laptop.

Alur produksi

Empat tahap, empat alat. Hasil tiap tahap menjadi bahan untuk tahap berikutnya.

Bagian 1 · Langkah 1–4

Siapkan server ReelForge di Google Colab

ReelForge berjalan sebagai notebook Colab yang menyalakan server render Remotion dan membukanya lewat Cloudflare Quick Tunnel. Cukup jalankan sekali di awal sesi.

  1. 1

    Buka notebook dan ubah jenis runtime

    Buka notebook ReelForge di Google Colab dan masuk dengan akun Google Anda. Pada menu atas klik Runtime, lalu pilih Ubah jenis runtime.

    Buka notebook ReelForge
  2. 2

    Pilih akselerator GPU T4

    Pada dialog yang muncul pilih Python 3 sebagai jenis runtime dan GPU T4 sebagai akselerator hardware, lalu klik Simpan.

    Tips: GPU T4 mempercepat encoding video. Jika kuota GPU habis, render tetap bisa jalan di CPU tetapi lebih lambat.

  3. 3

    Jalankan semua sel

    Klik Runtime → Jalankan semua (Ctrl+F9). Saat muncul peringatan Notebook ini tidak ditulis oleh Google, klik Tetap jalankan.

  4. 4

    Tunggu setup selesai dan buka Web Studio

    Log akan menampilkan proses instalasi Node, Chromium, FFmpeg, dan pembuatan tunnel. Setelah muncul tombol BUKA REELFORGE WEB STUDIO, klik tombol tersebut.

    Perhatian: Siapa pun yang memiliki URL tunnel bisa mengakses web ini. Jangan bagikan link-nya secara publik, dan biarkan tab Colab tetap terbuka selama bekerja.

Bagian 2 · Langkah 5–8

Registrasi ChatGPT

ChatGPT dipakai untuk menulis storyboard dan teks voice-over. Lewati bagian ini jika sudah punya akun.

  1. 5

    Daftar dengan email

    Buka chatgpt.com, klik Daftar gratis, lalu masukkan alamat email dan klik Lanjutkan.

  2. 6

    Masukkan kode verifikasi

    Cek kotak masuk email, salin kode verifikasi 6 digit, lalu tempel pada kolom Kode dan klik Lanjutkan.

  3. 7

    Isi nama dan usia

    Masukkan nama lengkap dan usia, lalu klik Lanjutkan. Setelah muncul halaman Semua sudah siap, klik Lanjutkan sekali lagi.

  4. 8

    Beranda ChatGPT siap digunakan

    Akun sudah aktif. Biarkan tab ini terbuka, kita akan kembali ke sini pada langkah pembuatan naskah.

Bagian 3 · Langkah 9–14

Registrasi Claude

Claude dipakai untuk mengubah naskah dan audio menjadi project Remotion lengkap dalam bentuk ZIP.

  1. 9

    Masuk dengan email

    Buka claude.ai, masukkan alamat email, lalu klik Lanjutkan dengan email.

  2. 10

    Klik tombol Masuk dari email

    Buka email dari Anthropic dan klik tombol Masuk. Tautan hanya berlaku 10 menit.

  3. 11

    Setujui ketentuan dan buat akun

    Centang persetujuan Consumer Terms dan Acceptable Use Policy, lalu klik Buat akun.

  4. 12

    Pilih penggunaan pribadi, lalu lewati penawaran paket

    Pilih Untuk penggunaan pribadi. Pada halaman paket, pilih Gunakan Claude secara gratis (lewati).

  5. 13

    Lewati aplikasi desktop dan lanjutkan

    Pada halaman aplikasi desktop klik Lewati. Pada halaman Sebelum chat pertama Anda klik Lanjutkan.

  6. 14

    Beranda Claude siap digunakan

    Akun Claude sudah aktif. Biarkan tab ini terbuka untuk langkah pembuatan project Remotion.

Bagian 4 · Langkah 15–18

Daftar Cartesia

Cartesia menyediakan text-to-speech dengan suara bahasa Indonesia yang natural. Kuota gratisnya cukup untuk beberapa video pendek.

  1. 15

    Buka cartesia.ai dan klik Try Cartesia

    Kunjungi cartesia.ai, lalu klik tombol Try Cartesia di pojok kanan atas.

  2. 16

    Isi form pendaftaran dan verifikasi email

    Isi nama depan, nama belakang, email, dan password, lalu klik Continue. Masukkan kode 6 digit yang dikirim ke email.

  3. 17

    Lewati survei onboarding

    Pada pertanyaan How did you hear about us? klik Skip. Pada Where do you want to start? pilih I'm exploring atau Start with Models.

  4. 18

    Buka menu Text-to-Speech

    Jika masuk ke halaman Agents, klik tab Models di pojok kiri bawah, lalu pilih menu Text-to-Speech di sidebar.

Bagian 5 · Langkah 19–21

Buat naskah dan voice-over text dengan ChatGPT

ReelForge menyediakan Master Prompt yang otomatis menyusun brief video. Anda cukup mengisi topik, durasi, dan gaya.

  1. 19

    Isi Master Prompt di ReelForge, salin bagian ChatGPT

    Di ReelForge Web Studio, bagian Prompt Library: isi Topik, Target durasi, Deskripsi, Target audiens, Call to action, dan Gaya visual. Pastikan tab ChatGPT aktif, lalu klik Salin prompt.

    Tips: Contoh gaya visual: Kinetic Typography, Flat 2D Vector Animation, Line Art, Minimalist Monoline.

    ReelForge belum dibuka? Pakai generator prompt ChatGPT di situs ini. Template dan hasilnya sama.

  2. 20

    Tempel prompt di ChatGPT

    Kembali ke tab ChatGPT, tempel prompt pada kotak chat dan kirim. ChatGPT akan membuat production file lengkap (brief, storyboard, palet warna) dan FULL TEXT VOICE-OVER FINAL.

  3. 21

    Salin teks voice-over dan unduh file TXT

    Salin seluruh teks pada bagian FULL TEXT VOICE-OVER FINAL (akan dipakai di Cartesia). Lalu unduh file motion_graphic_remotion.txt yang dilampirkan ChatGPT.

    Naskah ini juga menjadi acuan voice-over di storyboard. Jangan ubah isinya setelah audio dibuat agar subtitle tetap sinkron.

Bagian 6 · Langkah 22–24

Buat voice-over bahasa Indonesia di Cartesia

Ubah teks voice-over menjadi audio. Pilih suara berbahasa Indonesia agar pelafalannya natural.

  1. 22

    Tempel teks di Text-to-Speech

    Di halaman Text-to-Speech Cartesia, tempel teks voice-over pada kolom transcript. Lalu klik pilihan voice di panel kanan atas.

  2. 23

    Cari suara bahasa Indonesia

    Pada kotak pencarian ketik indonesia. Pilih salah satu suara, misalnya Galang – Serene Communicator atau Intan – Service Representative.

    Tips: Klik ikon play untuk mendengar contoh sebelum memilih. Atur speed sekitar 1.0x agar durasi sesuai target.

  3. 24

    Klik Generate dan unduh audio

    Klik Generate. Setelah audio muncul di bagian bawah, klik ikon Download audio untuk mengunduh file WAV/MP3.

Bagian 7 · Langkah 25–27

Buat project Remotion dengan Claude

Claude menerima naskah TXT dan audio, lalu membuat project Remotion lengkap (komposisi, animasi, subtitle, timing) dalam satu file ZIP.

  1. 25

    Pilih prompt untuk Claude di ReelForge

    Kembali ke ReelForge, pada Prompt Library klik tab Claude, lalu klik Salin prompt.

    Atau pakai generator prompt Claude di situs ini. Isian dari prompt ChatGPT ikut terbawa.

  2. 26

    Tempel prompt ke Claude dan upload file

    Di Claude, tempel prompt pada kotak chat. Klik ikon + lalu upload file TXT dari ChatGPT dan file audio dari Cartesia. Kirim pesan.

  3. 27

    Unduh file ZIP project

    Tunggu Claude selesai menyusun project. Di akhir jawaban akan ada lampiran remotion_reels_remotion.zip. Klik untuk mengunduhnya.

    Perhatian: Paket Free Claude memiliki batas penggunaan per 5 jam. Jika kena batas sebelum ZIP selesai, tunggu reset lalu minta Claude melanjutkan.

Bagian 8 · Langkah 28–30

Render video MP4 di ReelForge

Langkah terakhir: upload ZIP ke ReelForge. Server di Colab akan menginstal dependency, me-render frame, dan menggabungkannya dengan audio.

  1. 28

    Upload ZIP dan mulai render

    Pada panel ZIP → Video MP4, seret file ZIP atau klik Pilih atau seret file ZIP. Pilih Render Mode: Auto, centang kotak konfirmasi, lalu klik Upload & Render MP4.

  2. 29

    Tunggu proses render

    Progress bar menampilkan tahap: unzip, install dependency, render frame, dan encode. Log detail bisa dilihat pada kotak hitam di bawahnya.

    Render 30 detik video biasanya memakan waktu 3–8 menit tergantung kompleksitas animasi.

  3. 30

    Selesai, video siap diputar

    Setelah 100%, muncul bagian Video siap diputar. Putar untuk mengecek hasil, lalu unduh MP4 dan unggah ke Instagram Reels.

Tanya jawab

Render gagal dengan pesan 'Lihat log untuk detail'. Apa yang harus dicek?

Buka log di panel render. Penyebab paling umum: ZIP tidak berisi package.json di root, atau dependency gagal diinstal. Minta Claude memperbaiki struktur project lalu upload ulang.

Subtitle tidak sinkron dengan suara.

Timing subtitle dibuat Claude secara estimasi. Edit file src/data/captions.ts di dalam ZIP, sesuaikan waktu per kalimat, lalu zip ulang dan render kembali.

URL ReelForge tidak bisa dibuka lagi.

Tunnel Cloudflare mati saat runtime Colab berhenti. Jalankan ulang semua sel di Colab untuk mendapat URL baru.
