Generator prompt Claude

Buat prompt agar Claude membangun video Remotion dari storyboard ChatGPT dan audio Cartesia. Pilih hasilnya: MP4 siap upload, ZIP project, atau keduanya.

  1. 1ChatGPTStoryboard + voice-over
  2. 2ClaudeVideo MP4 atau ZIP

Siapkan dua lampiran

  1. File motion_graphic_[topik].txt dari ChatGPT.
  2. File audio MP3/WAV dari Cartesia.
  3. Akun Claude. Paket Free punya batas penggunaan per 5 jam.

Detail video

MP4 dirender Claude bila lingkungannya mendukung; kalau tidak, Claude memberi ZIP sebagai cadangan. ZIP bisa dirender sendiri di laptop.

5–180 detik. Anggaran voice-over: 20 detik ≈ 40–44 kata.

Samakan dengan isian prompt ChatGPT agar project konsisten dengan storyboard.

3–5 fakta dari sumber resmi. Kalau kosong atau kurang, ChatGPT diminta bertanya dulu, bukan menebak.

Cara mengucapkan istilah asing di voice-over. Teks layar tetap memakai tulisan aslinya.

Kosong berarti “modern premium”.

Menentukan tampilan karakter, latar, dan gerak. Gaya “tiruan 3D” dibuat dengan 2D (shading dan perspektif), jadi tetap aman dirender di laptop maupun Colab.

Edukasi: problem → stakes → solusi → cara kerja → payoff, dengan satu analogi. Retensi: hook → setup → beat → payoff/loop. Diadaptasi dari motion-skills (iart.ai, MIT).

Bold cocok untuk edukasi, Bounce untuk hiburan, Clean untuk nada profesional. Preset diadaptasi dari claude-shorts (MIT).

Isian tersimpan otomatis di browser ini saja, tidak dikirim ke server, dan ikut terpakai di halaman prompt ChatGPT.

Cara pakai

Panduan lengkap dengan tangkapan layar ada di tutorial Remotion.

  1. Cek isian

    Gunakan isian yang sama dengan prompt ChatGPT. Prompt ini meminta Claude membaca segmen VO, design tokens, dan field storyboard dari TXT; durasi tetap mengikuti audio Cartesia.

  2. Tempel prompt dan lampirkan file

    Di Claude, tempel prompt, klik + untuk melampirkan TXT dan audio, lalu kirim. Lihat langkah 22.

  3. Unduh MP4 atau ZIP

    Unduh reels_[topik].mp4 dan langsung unggah ke Reels. Kalau hanya dapat ZIP (umum di paket Free), ubah jadi MP4 di laptop atau Google Colab. Lihat opsi di bawah.

Dapat ZIP? Ubah jadi MP4

Di paket Free, sandbox Claude biasanya tanpa internet, jadi Claude hanya bisa memberi ZIP dan tidak bisa merender. Pilih salah satu cara berikut untuk mengubahnya jadi MP4.

Opsi A

Di laptop

Instal Node.js sekali, lalu jalankan beberapa perintah di terminal. Cocok kalau Anda nyaman memakai terminal dan ingin hasilnya cepat.

Ikuti langkah di laptop
Opsi B · tanpa instalasi

Di Google Colab

Unggah ZIP ke Render Studio yang berjalan di Google Colab, lalu unduh MP4-nya. Butuh akun Google, tanpa instal apa pun di laptop.
