Kebijakan Privasi

Terakhir diperbarui: 3 Oktober 2026 · Status: draf

Draf. Dokumen ini ditulis berdasarkan cara kerja aplikasi saat ini dan belum ditinjau oleh penasihat hukum. Isinya dapat berubah sebelum aplikasi dirilis secara publik.

1. Ringkasan

  • Aplikasi Android Jelajah Nusantara versi 1 berjalan offline. Materi dan soal sudah ada di dalam aplikasi. Build web perlu dimuat dari server (lihat bagian 4).
  • Progres permainan, nama panggilan, avatar, dan pengaturan disimpan secara lokal di perangkat Anda dan tidak dikirim ke server kami.
  • Tidak ada akun, tidak ada iklan, dan tidak ada SDK analitik atau pelacakan pihak ketiga di versi 1.
  • Situs ini tidak memasang cookie, analitik, atau skrip pihak ketiga. Penyedia hosting dapat mencatat log akses teknis secara terpisah (lihat bagian 4).
  • Jika Anda mengajukan diri sebagai tester Android, email akun Google dan pesan opsional Anda dikirim oleh Anda sendiri lewat WhatsApp kepada admin, lalu email ditambahkan secara manual ke daftar tester Google Play (lihat bagian 5).

2. Cakupan

Kebijakan ini berlaku untuk:

  • situs web Siap Digital ini, termasuk formulir pendaftaran tester di halaman aplikasi; dan
  • aplikasi Jelajah Nusantara versi 1, termasuk build demo pra-rilis v0.1.1, versi web, dan build Android yang diuji tertutup di Google Play.

Jika versi mendatang menambahkan fitur yang memakai jaringan, iklan, atau akun, kebijakan ini akan diperbarui.

Pada Android, data ini disimpan di penyimpanan internal aplikasi. Pada build web, data disimpan di penyimpanan browser Anda. Kami tidak menyimpan cadangan data Anda. Perlu diketahui, Android dapat mencadangkan data aplikasi ke akun Google Anda melalui fitur cadangan bawaan perangkat, sesuai pengaturan cadangan Anda; cadangan tersebut dikelola oleh Google, bukan oleh kami.

Aplikasi tidak meminta nama asli, email, nomor telepon, lokasi, kontak, ataupun akses ke foto atau kamera. Build Android rilis v0.1.1 tidak meminta izin akses internet.

Koin virtual tidak dapat dibeli, tidak dapat ditukar, dan tidak bernilai uang. Versi 1 tidak memiliki pembelian dalam aplikasi.

4. Jaringan, situs, dan log hosting

Kami tidak mengumpulkan data pribadi melalui aplikasi maupun situs ini, kecuali permintaan tester yang Anda kirim sendiri lewat WhatsApp (bagian 5). Namun, setiap kali sebuah berkas dimuat lewat internet, server yang menyajikannya dapat mencatat informasi teknis. Hal ini terpisah dari data di dalam aplikasi:

  • Situs ini. Saat Anda membuka situs ini, penyedia hosting dapat mencatat log akses standar, misalnya alamat IP, waktu akses, halaman yang diminta, dan jenis browser. Log tersebut dikelola oleh penyedia hosting sesuai kebijakannya sendiri. Kami tidak menambahkan cookie, analitik, atau pelacak ke situs ini.
  • Versi web aplikasi. Versi web disajikan di eduquest.siapdigital.id dari sebuah server, yang dapat mencatat log akses serupa. Dengan pengaturan bawaan Flutter, build web juga dapat memuat komponen tampilan dan font dari server Google, sehingga alamat IP Anda dapat terlihat oleh Google. Progres permainan Anda tidak ikut dikirim.
  • Google Play dan GitHub. Build Android untuk pengujian dibagikan melalui Google Play, dan build demo juga dibagikan melalui GitHub Releases dengan akses terbatas. Mengikuti pengujian, mengunduh, atau memasang aplikasi lewat layanan tersebut tunduk pada kebijakan privasi Google dan GitHub.
  • Aplikasi Android. Build rilis v0.1.1 tidak meminta izin internet dan tidak mengirim progres Anda ke server kami. Cadangan bawaan Android (lihat bagian 3) diatur oleh perangkat dan akun Google Anda.

5. Permintaan menjadi tester (WhatsApp)

Versi Android Jelajah Nusantara diuji tertutup di Google Play. Untuk ikut menguji, Anda dapat mengisi formulir di halaman aplikasi. Pemrosesan ini terpisah dari data permainan di dalam aplikasi (bagian 3).

  • Data yang diminta. Email akun Google Anda (wajib) dan pesan opsional, ditambah nama aplikasi yang ingin diuji.
  • Cara data dikirim. Situs ini tidak mengirim isian formulir ke server mana pun dan tidak menyimpannya di browser. Saat Anda menekan tombol Kirim permintaan lewat WhatsApp, browser hanya membuka tautan WhatsApp (wa.me) yang memuat draf pesan berisi data tersebut, sehingga WhatsApp (Meta) menerima draf itu saat tautan dibuka. Pesan baru terkirim jika Anda sendiri menekan Kirim di WhatsApp, kepada admin tester Siap Digital di nomor 088275426716.
  • Tujuan. Email dipakai hanya untuk mengelola tester: admin menambahkannya secara manual ke daftar tester Google Play dan dapat membalas pesan Anda tentang akses pengujian. Penambahan tidak otomatis dan permintaan belum tentu disetujui.
  • Pihak ketiga. Pesan WhatsApp diproses oleh WhatsApp (Meta) sesuai kebijakan privasinya, dan nomor WhatsApp Anda terlihat oleh admin. Email yang ditambahkan ke daftar tester diproses oleh Google sebagai bagian dari Google Play Console dan program pengujian Google Play, sesuai kebijakan privasi Google.
  • Penyimpanan dan penghapusan. Jangka waktu penyimpanan pesan dan daftar tester belum ditetapkan dalam draf ini. Anda dapat meminta agar email Anda dikeluarkan dari daftar tester dengan mengirim pesan WhatsApp ke nomor yang sama, dan Anda dapat berhenti menjadi tester melalui tautan pengujian Google Play.

Jangan menuliskan kata sandi atau data sensitif di formulir maupun di WhatsApp, dan daftarkan hanya email akun Google milik Anda sendiri.

6. Layanan pihak ketiga

Versi 1 tidak memuat SDK iklan, analitik, pelaporan kerusakan, atau login pihak ketiga. Tautan ke layanan lain (seperti GitHub, Google Play, dan WhatsApp) mengikuti kebijakan privasi layanan tersebut.

Masukan yang Anda kirim melalui GitHub Issues bersifat publik. Mohon jangan menuliskan data pribadi di sana.

7. Anak-anak

Aplikasi dirancang untuk pengguna berusia 12 tahun ke atas dan dapat dipakai oleh pelajar. Karena aplikasi tidak meminta data pribadi, tidak memuat iklan, dan tidak mengirim progres ke server kami, kami tidak dengan sengaja mengumpulkan data pribadi anak. Orang tua atau wali dapat menghapus seluruh data permainan kapan saja (lihat bagian 8). Pengguna di bawah umur sebaiknya mengajukan diri sebagai tester (bagian 5) bersama atau dengan izin orang tua atau wali.

8. Menghapus data Anda

Karena data disimpan di perangkat Anda, Anda yang memegang kendali:

  • gunakan tombol hapus data permainan di menu Pengaturan aplikasi;
  • hapus data aplikasi atau copot pemasangan aplikasi di Android; atau
  • hapus data situs di browser Anda untuk build web.

Data yang sudah dihapus tidak dapat kami pulihkan karena kami tidak menyimpan salinannya. Cadangan bawaan Android di akun Google Anda, jika aktif, dapat dikelola melalui pengaturan cadangan perangkat atau akun Google Anda.

9. Perubahan kebijakan

Kami akan memperbarui halaman ini jika cara aplikasi atau situs menangani data berubah, dan mengubah tanggal “Terakhir diperbarui” di atas.

10. Kontak

Alamat kontak resmi untuk pertanyaan privasi belum tersedia, dan identitas hukum penyelenggara belum dicantumkan di halaman ini. Sementara itu, Anda dapat mengirim pertanyaan umum melalui GitHub Issues. Isu bersifat publik, jadi jangan sertakan data pribadi. Nomor WhatsApp di bagian 5 khusus untuk permintaan dan pengelolaan tester.
