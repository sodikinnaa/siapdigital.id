Kebijakan Privasi

Terakhir diperbarui: 3 Oktober 2026 · Status: draf

Draf. Dokumen ini ditulis berdasarkan cara kerja aplikasi saat ini dan belum ditinjau oleh penasihat hukum. Isinya dapat berubah sebelum aplikasi dirilis secara publik.

1. Ringkasan

  • Aplikasi Android Jelajah Nusantara versi 1 berjalan offline. Materi dan soal sudah ada di dalam aplikasi. Build web perlu dimuat dari server (lihat bagian 4).
  • Progres permainan, nama panggilan, avatar, dan pengaturan disimpan secara lokal di perangkat Anda dan tidak dikirim ke server kami.
  • Tidak ada akun, tidak ada iklan, dan tidak ada SDK analitik atau pelacakan pihak ketiga di versi 1.
  • Situs ini tidak memasang cookie, analitik, atau skrip pihak ketiga. Penyedia hosting dapat mencatat log akses teknis secara terpisah (lihat bagian 4).

2. Cakupan

Kebijakan ini berlaku untuk:

  • situs web Siap Digital ini; dan
  • aplikasi Jelajah Nusantara versi 1, termasuk build demo pra-rilis v0.1.1 untuk Android dan web.

Jika versi mendatang menambahkan fitur yang memakai jaringan, iklan, atau akun, kebijakan ini akan diperbarui.

3. Data di dalam aplikasi

Aplikasi menyimpan data berikut hanya di perangkat Anda agar Anda dapat melanjutkan permainan:

Data yang disimpan lokal oleh aplikasi
DataKegunaan

Pada Android, data ini disimpan di penyimpanan internal aplikasi. Pada build web, data disimpan di penyimpanan browser Anda. Kami tidak menyimpan cadangan data Anda. Perlu diketahui, Android dapat mencadangkan data aplikasi ke akun Google Anda melalui fitur cadangan bawaan perangkat, sesuai pengaturan cadangan Anda; cadangan tersebut dikelola oleh Google, bukan oleh kami.

Aplikasi tidak meminta nama asli, email, nomor telepon, lokasi, kontak, ataupun akses ke foto atau kamera. Build Android rilis v0.1.1 tidak meminta izin akses internet.

Koin virtual tidak dapat dibeli, tidak dapat ditukar, dan tidak bernilai uang. Versi 1 tidak memiliki pembelian dalam aplikasi.

4. Jaringan, situs, dan log hosting

Aplikasi dan situs ini memang tidak mengumpulkan data pribadi, tetapi setiap kali sebuah berkas dimuat lewat internet, server yang menyajikannya dapat mencatat informasi teknis. Hal ini terpisah dari aplikasi:

  • Situs ini dan build web. Saat Anda membuka situs ini atau build web aplikasi dari sebuah server, penyedia hosting server tersebut dapat mencatat log akses standar, misalnya alamat IP, waktu akses, halaman atau berkas yang diminta, dan jenis browser. Log tersebut dikelola oleh penyedia hosting sesuai kebijakannya sendiri. Kami tidak menambahkan cookie, analitik, atau pelacak ke situs ini.
  • Unduhan dari GitHub. Build demo dibagikan melalui GitHub Releases. Mengakses atau mengunduh dari GitHub tunduk pada kebijakan privasi GitHub.
  • Setelah terpasang. Bermain di aplikasi Android tidak mengirim progres Anda ke mana pun.

5. Layanan pihak ketiga

Versi 1 tidak memuat SDK iklan, analitik, pelaporan kerusakan, atau login pihak ketiga. Tautan ke layanan lain (seperti GitHub) mengikuti kebijakan privasi layanan tersebut.

Masukan yang Anda kirim melalui GitHub Issues bersifat publik. Mohon jangan menuliskan data pribadi di sana.

6. Anak-anak

Aplikasi dirancang untuk pengguna berusia 12 tahun ke atas dan dapat dipakai oleh pelajar. Karena aplikasi tidak meminta data pribadi, tidak memuat iklan, dan tidak mengirim progres ke server, kami tidak dengan sengaja mengumpulkan data pribadi anak. Orang tua atau wali dapat menghapus seluruh data permainan kapan saja (lihat bagian 7).

7. Menghapus data Anda

Karena data hanya ada di perangkat Anda, Anda yang memegang kendali penuh:

  • gunakan tombol hapus data permainan di menu Pengaturan aplikasi;
  • hapus data aplikasi atau copot pemasangan aplikasi di Android; atau
  • hapus data situs di browser Anda untuk build web.

Data yang sudah dihapus tidak dapat kami pulihkan karena kami tidak menyimpan salinannya.

8. Perubahan kebijakan

Kami akan memperbarui halaman ini jika cara aplikasi atau situs menangani data berubah, dan mengubah tanggal “Terakhir diperbarui” di atas.

9. Kontak

Alamat kontak resmi untuk pertanyaan privasi belum tersedia. Sementara itu, Anda dapat mengirim pertanyaan umum melalui GitHub Issues. Isu bersifat publik, jadi jangan sertakan data pribadi.
